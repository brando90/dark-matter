# E2 Amendment (2026-11-26): shared observations, control noise, and unavailable sweep correction

As of 2026-11-26. Author: ub9sc; resume harness Codex CLI, GPT-6 Astra ultra via Vals; Python CPU fits on skampere1. This amendment is committed and pushed before revised runs and before results.md. PREREG.md remains unchanged.

Why do the tiniest models live off the scaling curve, and what correction brings them back? This amendment repairs implementation and records a measurement that the preregistered return-to-curve formula cannot supply. It does not change the scientific question, data, fitted laws, real-data thresholds, bootstrap sample counts, reference-size cutoff, factor definitions, or dataset decision rule.

The original implementation and outputs are preserved in [checkpoint commit 641e6c6](https://github.com/brando90/dark-matter/commit/641e6c6); revised runs will also retain them in `results/original_2026-11-26/`. Original verification passed reproduction and its limited arithmetic check, but failed both preregistered controls: positive J EXPLAINS 4/20 and M RETURNS 17/20; planted-fast-term J not EXPLAINS 17/20 and M STAYS OFF 10/20. These failures remain part of the result and are not relabeled as passing.

1. **Synthetic-control noise.** The fixed synthetic generator has Gaussian noise sd 0.003 nats. Its small-observation bootstrap sd and the same decision functions' two-sd threshold will use that known synthetic sd, rather than the empirical rw 5M seed sd 0.0619198781. The real analysis still uses the empirical seed sd exactly as preregistered. The synthetic truth, planted fast term (+0.3 nats at 5M, exponent 1.4), 20 replicates, random seeds, and both 80% control gates are unchanged. The existing control bootstrap counts (300 N-only, 100 joint per replicate) remain unchanged and are labeled separately from the real analysis (2,000 N-only/sweep, 500 joint).
2. **Reused synthetic observations.** Generate each synthetic `(N,D)` observation once, and reuse it where the TC20 ladder overlaps the joint-design observations. The original script generated different noisy values for these overlaps. Synthetic observations at distinct checkpoints remain independently perturbed under this model.
3. **Shared reference bootstrap innovations.** Assign one fixed standard-normal bootstrap vector to each observed `(dataset, recipe, width, D)` value, reused wherever that value enters a fit or factor. This includes reference-size TC20 values reused by the joint fit and exactly coincident final/checkpoint values. For reference observations, apply the relevant fit's preregistered parametric mean and residual sd to that common standardized innovation; the N-only and joint parametric means and residual sd differ, so their synthetic reference responses need not be numerically identical. Reuse the entire perturbed small observation when it appears in multiple factors. Distinct interpolated checkpoint values are separate observations under this bootstrap; this does not model correlation between different checkpoints of the same training run.
4. **Resumable output.** Save bootstrap draws and metadata to disk, with partial joint predictions every 25 fits and completed N-only/sweep draws after each condition. Cache validity includes input arrays, count convention, bootstrap size, random state, and an implementation version. Report actual persisted draw counts. The first implementation cached only final CSV summaries and could not demonstrate or resume its individual draws.
5. **Unavailable rw 9M sweep correction.** The sweep has no 9M configuration. Therefore G_9M and the preregistered corrected matched excess M_9M = X^J_9M - G_9M are unavailable on rw. Mark M_9M unavailable/UNDETERMINED; report the uncorrected joint excess descriptively. Do not substitute G_9M = 0. The dataset rule remains unchanged: all three RETURNS are required for CONFOUND EXPLAINS; at least two STAY OFF for CONFOUND DOES NOT EXPLAIN IT; otherwise PARTIAL.
6. **Verification reporting.** Report software integrity/reproduction checks separately from the unchanged scientific control gates. If either corrected fixed control gate still fails, label the gate FAILED and all data-based classifications conditional/descriptive; do not present a validated scientific verdict. Do not change coefficients, seeds, 80% thresholds, or real-data decision thresholds in response to this failure. A deterministic arithmetic or recovery check cannot replace the failed statistical controls.

The analysis is numerical Python research, not a Lean proof; Lean and differential testing are not applicable. No paid compute, API call, or external message is needed.
